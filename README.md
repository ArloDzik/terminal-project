# Terminal Project

A modular financial analytics platform inspired by Bloomberg Terminal, built as a
guided learning project in Python, software engineering, and financial data analysis.

## Status
In progress — Phase 0 (project skeleton)

## Setup
1. Clone the repo
2. `python -m venv .venv`
3. Activate it: `.venv\Scripts\Activate.ps1` (Windows) or `source .venv/bin/activate` (Mac/Linux)
4. `pip install -r requirements.txt`
5. Copy `.env.example` to `.env` and fill in your API keys
